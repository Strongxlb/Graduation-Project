# Legacy figures

Nothing here is used by the paper. These are exports from the earlier exploratory notebooks
(`03_pipeline_net3_01`, `03_pipeline_net3_02`, `wntr_chlorine_getting_started_4`) and from the
first GLUE-era risk map. They predate the current pipeline: the assessment horizon, the
weighting rule and the concentration-unit handling all changed afterwards, so the numbers on
these panels do not match the results reported in the paper.

They are kept because they record how the work developed, not as evidence for any claim.

Every figure the paper uses is in `../paper/`, regenerated from the cached artifacts by
`Net3/paper_figs.py` on each run of `build.sh`.

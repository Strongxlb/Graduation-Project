## 1. 老师 6.12 笔记还原

### 1.1 三步走路线图（IMG_4132）

- **① 正向问题（Forward）**：给定水源初始浓度 `C₀`、管壁衰减系数 `kw`（按管材），算出下游各节点浓度 `C₁, C₂, C₃ …`（图中打问号 = 待求）。
- **② 参数/情景（Sensitivity）**：固定 `C₀`，改变 `kw`（按管材/管组），看 `C₁, C₂, C₃` 怎么变；引入**管道分组**（约 `20%` 老管 / 老铸铁管 `CI old`）。
- **③ 反问题（Inverse）**：`C₀, kw（不同管道/管材）` → 模拟出 `C₁, C₂, C₃` → **加随机噪声** → 当作"测量值" → 反推参数（`inverse problem`）。

### 1.2 右侧三件明确待办（IMG_4131）

1. `zero order decay` —— 用**零阶衰减**建模。
2. `review` —— 文献回顾。
3. `network visualised` —— 把管网可视化。

### 1.3 其它建模要点（IMG_4131）

- 浓度随时间衰减，时间尺度约 **72 小时**（例 `1 → 0.2 mg/L`、`1.2 → 0.8 mg/L`）。
- `0-order decay → time / residence`：零阶衰减与**停留时间 / 水龄**挂钩。
- `mg/L → ppm → sensor`：传感器读数是 **noisy（带噪声）** 的。
- 总衰减 = 本体反应 `kb`（bulk）+ 管壁反应 `kw`（wall），其中 `kw = f(pipe material)`（管壁反应取决于管材）。

## 3. 我现在要做的事（完整待办清单）

> 优先级：**A 组 = 这周把 Net3 流程走通（老师本次重点）** → **B 组 = 老师 6.12 明确点名的事** → **C 组 = 走通后再切真实数据**。

### A. 把 Net3 整条流程走通（最高优先）

- [ ] **A1 加零阶衰减选项**：给 `simulate_chlorine()` 增加 `bulk_order / wall_order` 参数（或新函数），支持 `order=0`。对照老师 `zero order decay` 要求，跑一遍零阶结果。
  - 一阶：`dC/dt = -k·C`；零阶：`dC/dt = -k`（衰减速率与浓度无关，与停留时间线性相关）。
- [ ] **A2 给合成观测加随机噪声**（补全练习 5 的第 ③ 步）：

  **公式**：

  ```
  C_meas(t) = C_sim(t) + ε,   ε ~ Normal(0, σ²)
  ```

  **性质**：
  - `σ` 取传感器量级（如 `±0.02 mg/L` 或满量程 `±5%`）。
  - 同时可加比例噪声 `ε ~ Normal(0, (r·C_sim)²)` 模拟相对误差。
- [ ] **A3 端到端闭环**：`真值参数 → 正向模拟 → 加噪声 → 反演 → 恢复参数`，并报告恢复误差（`|k̂ − k_true|`），验证整条 pipeline 正确。
- [ ] **A4 显式算水龄 / 停留时间**：用 WNTR 的 `quality.parameter='AGE'` 跑一次，把节点水龄和 `0-order decay → time/residence` 对应起来。
- [ ] **A5 ② 按管材改 `kw`**：按"管组/管材"（如 20% 老管）给不同 `kw`，模拟管材异质，看节点浓度变化（已在 `03_pipeline_net3.ipynb` 第 1 步实现）。
